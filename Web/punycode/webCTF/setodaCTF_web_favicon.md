# setodaCTF Web問題 解説：Mx.Flag（faviconに隠されたフラグ）

## 問題概要
「旗（Flag）」から手紙が届く。「うまく隠れた」ので見つけてほしい、という内容。
ソースコードもユーザー入力も無く、1ページ内で完結するタイプ。

## 解法の流れ

### 1. 手紙のヒントを読み解く
- 「旗」＝英語で **flag**。差出人がフラグ自身。
- 「うまく隠れることができた」＝ページのどこかに隠れている。
- ポートスキャン（nmap）などは不要。「見えない場所」を探す問題。

### 2. HTMLソースを確認
HTML本体はきれいで隠し要素は無し。ただし外部ファイルを2つ読み込んでいた。
```html
<link rel="stylesheet" href="assets/css/style.css">
<link rel="icon" type="image/png" href="images/favicon.png">
```

### 3. 外部ファイルを順に調査
- `style.css` → 中身は短く、フラグ無し。
- `favicon.png` → **画像が表示されない**（怪しい）。

### 4. faviconの正体を暴く
`favicon.png` をダウンロードし、中身の種類を確認。
```bash
file favicon.png
```
結果：
```
favicon.png: ASCII text
```

- 拡張子は `.png`（画像）なのに、中身は **ただのテキスト**。
- だから画像として表示されなかった。
- 「うまく隠れた」＝**画像のふりをしたテキストファイル**だった。

### 5. 中身を表示
```bash
cat favicon.png
```
→ フラグが記載されていた。

## フラグ
```
flag{Mr_Flag_hiding_in_the_favicon}
```

## 使ったコマンド
| コマンド | 役割 |
|----------|------|
| `file` | ファイルの本当の種類を判定（拡張子でなく中身で判断） |
| `strings` | バイナリから読める文字列を抽出 |
| `cat` | ファイルの中身を表示 |

## ポイント
- **拡張子と中身は一致するとは限らない**。表示できない画像は「中身が画像でない」サイン。
- `file` コマンドで正体を確認するのがセオリー。
- favicon（サイトのアイコン）は見落とされやすく、隠し場所に使われることがある。

## 対策
- 公開ファイルの中身と拡張子を一致させ、余計な情報を含めない。
- 不要なファイルは公開ディレクトリに置かない。
