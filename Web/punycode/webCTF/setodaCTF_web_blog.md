# setodaCTF Web問題 解説：局長ブログの情報漏洩（隠し画像）

## 問題概要
局長ブログで機密情報が漏洩している。サイトを調査し、漏洩している機密情報を特定する。

## 解法の流れ

### 1. 記事を確認
記事URL：`web006/20210603.html`
本文に「昨日の記事について」という記述があり、連番URLを推測。

### 2. ヒントの発見
記事のソースコードのコメントアウト内に画像パスが埋まっていた。
```html
<img src="images/20210603001b.jpg" alt="" />
```

### 3. ファイル名を分析
`20210603001b.jpg` を分解：

| 部分 | 意味 |
|------|------|
| `20210603` | 日付 |
| `001` | 連番（1枚目） |
| `b` | バージョン違い（a, b...） |

### 4. 攻略
この画像 `images/20210603001b.jpg` に直接アクセス。
記事には表示されていない隠し画像で、ここに機密情報（フラグ）が写り込んでいた。

## ポイント
- HTMLコメント `<!-- -->` は開発の痕跡が残りやすい。ソース確認は基本。
- 記事に載っていない画像でも、URLを直接叩けば見えてしまう。
- ファイル名の規則性（日付・連番・記号）から隠しファイルを推測できる。

## 対策
- 公開ディレクトリに機密画像を置かない。
- 不要なファイルはサーバーから削除する。
- コメントアウトに内部情報を残さない。
