# setodaCTF 問題 解説：Google検索演算子でlogin.phpを探す

## 問題概要
組織のドメインで `login.php` が不用意に公開されていないかGoogleで確認する。
URLに `login.php` を含むページを検索するための、検索演算子を含む検索語句をフラグ形式で答える。

- 回答例（問題文より）：ファイルタイプを限定する場合 → `flag{filetype:pdf}`
- 英字はすべて小文字。

## 前提知識
- **検索演算子**：Google検索で条件を絞るための特別なキーワード。`演算子:値` の形で使う。
- このように検索演算子を駆使して公開情報を探す調査手法を **Google Hacking（Googleダーク）** と呼ぶ。攻撃者が公開されすぎた情報を見つけるのにも使われる。

## 主な検索演算子
| 演算子 | 働き |
|--------|------|
| `site:` | 特定ドメインに限定 |
| `filetype:` | ファイル形式で限定（pdf, xlsx 等） |
| `intitle:` | ページタイトルに含む |
| `intext:` | ページ本文に含む |
| **`inurl:`** | **URLに含む** |

## 解法
- 求めるのは「URLに `login.php` を含むページ」。
- 「URL内を検索する」＝ `in`（〜の中に）＋ `url` → **`inurl`**（ちょうど5文字）。
- 回答例と同じ形式に当てはめる。

## フラグ
```
flag{inurl:login.php}
```

## ポイント
- 検索演算子は `演算子:値` の形。演算子名の意味（in + url = URL内）から推測できる。
- 実務では `site:` と組み合わせて `site:example.com inurl:login.php` のように使い、自組織の情報漏洩を点検できる。
