# setodaCTF 問題 解説：MACアドレスOUIを使った暗号

## 問題概要
友人が作った暗号を解く。公開情報に基づいて解けるとのこと。
```
00:03:93 = A
00:01:A9 = B
04:2A:E2 = C
```

## ヒントの読み解き
- `00:03:93` の形式（16進2桁 × 3、`:`区切り）は **MACアドレス**の前半部分。
- **MACアドレス**：ネットワーク機器ごとに割り当てられた固有の番号。
- **OUI（Organizationally Unique Identifier）**：MACアドレスの前半3バイト。**製造メーカー**を示す部分。
- 「公開情報に基づき解ける」＝ OUIとメーカーの対応は**誰でも調べられる公開データベース**がある。

## ルールの発見と検証
各OUIのメーカー名を調べ、その**頭文字**を取る。

| OUI | メーカー | 頭文字 |
|-----|---------|--------|
| `00:03:93` | Apple | **A** |
| `00:01:A9` | BMW | **B** |
| `04:2A:E2` | Cisco | **C** |

→ 「OUIのメーカー名の頭文字」というルールが確定。

## 暗号文を解読
フラグ内の5つのOUIを同じ方法で変換：

| OUI | メーカー | 頭文字 |
|-----|---------|--------|
| `2C:C2:60` | Oracle | **O** |
| `FC:EC:DA` | Ubiquiti | **U** |
| `00:02:B3` | Intel | **I** |
| `AC:44:F2` | Yamaha | **Y** |
| `FC:4E:A4` | Apple | **A** |

つなげると **OUIYA**。
（暗号のテーマ「**OUI**」＋「YA」を掛けた言葉遊び。）

## 調べ方
- Webで「OUI検索」「MAC vendor lookup」などのサイトにOUIを入力。
- コマンド/プログラムなら、OUIデータベース（IEEE公開）を使うライブラリ（例：Pythonの `netaddr`）で調べられる。
```python
from netaddr import EUI
e = EUI('2C-C2-60-00-00-00')
print(e.oui.registration().org)   # → Oracle Corporation
```

## ポイント
- `XX:XX:XX` の16進3組を見たら MACアドレス/OUI を疑う。
- OUIとメーカーの対応は公開情報（IEEE登録）。オフラインDBでも検索可能。
- まず与えられた例（A,B,C）でルールを検証してから本文に適用するのが確実。
